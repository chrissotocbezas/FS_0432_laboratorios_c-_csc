## Instrucciones de Ejecución.

1. Como primera instrucción se debe ejecutar el siguiente código.

g++ -p main.x main.cpp funciones.cpp integracion.cpp

Esto para compilar cada uno de los archivos y guardarlos en un ejecutable (main.x).

2. Con el comando ./main.x, ejecutamos el programa.
3. Los resultados deberán de mostrarse en la consola de la terminal.
4. Con el comando ./main.x > output.txt, trasladamos los resultados al archivo output.txt que generamos con nuestro método de Simpson.
